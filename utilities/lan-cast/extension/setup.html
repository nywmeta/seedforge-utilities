LAN CAST

Your browser. Your TV.

One-time setup for direct video casting over your local network.

1 Install the local helper

LAN Cast uses a small helper to discover and control UPnP / DLNA playback devices. Install Python 3, then open Install on Mac.command on macOS or Install on Windows.cmd on Windows from the extracted lan-cast folder. Enter the extension ID below and your browser when prompted. For Opera GX on a Mac, choose Opera GX; choose Opera for the standard Opera browser.

Alternatively, open a terminal in that folder and run the command below. Use the command on Linux.

Choose the browser where this extension is loaded.

The command includes this extension’s ID.

Extension ID

If you move or load a different copy of the extension, its ID may change. Run the installer again with the ID shown by that copy.

2 Connect your TV

Turn the TV on and connect it to the same local network as this computer. A guest network or router isolation can prevent discovery. The TV must expose a UPnP / DLNA media renderer with playback controls.

Open the LAN Cast popup and select Find TVs. If discovery is blocked, you can try the TV’s IP address or its complete UPnP device description URL.

3 Choose and cast a stream

Open a video webpage and start its video. Open LAN Cast, choose Scan page, select a stream and a TV, then select Cast to TV. You can also paste a complete HTTP or HTTPS video URL.

The TV fetches the stream itself. The stream must use a format it supports and be accessible without your browser’s cookies, session, or extra request headers. Network candidates are unverified; HLS and DASH playback depends on the TV and the stream.

Know the limits

Browser-only blob URLs and DRM video are unsupported. This extension sends a media URL; it does not mirror your tab or transcode video. A TV accepting a command does not prove it can decode the stream. Check the picture on the TV and refresh playback status if needed.

Open the extension popup again after installation.
